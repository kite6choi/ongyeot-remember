# T25: 데모 체크리스트

창업 심사 데모 시연 가이드 및 체크리스트입니다.

## 시나리오 (spec.md 7장 기준)

### 시나리오 1: 체험 진입 (3초 이내)

**시연 단계:**
1. 데모 URL 접속: `https://your-app.vercel.app/?start=demo`
2. 자동 로딩 확인
3. 홈 화면 도달

**확인 항목:**
- [ ] 3초 이내 홈 화면 표시
- [ ] "떠나보낸 지 N일째" 표시
- [ ] 반려동물 정보 표시 (이름: 몽이, 종: 강아지)

**장애 시 대처:**
- 로딩 지연: 새로고침 (F5)
- 오류 발생: 백업 시연 영상 재생

---

### 시나리오 2: 공감 대화 (2초 이내 첫 응답)

**시연 단계:**
1. "대화" 탭 선택
2. 메시지 입력 및 전송
3. SSE 스트리밍 응답 확인

**시연 문장:**
- "보고 싶어요. 너무 보고 싶어요."
- "제가 더 일찍 병원에 데려갔어야 했는데..."
- "오늘 처음으로 산책을 나갔어요."

**확인 항목:**
- [ ] 2초 이내 첫 글자 표시
- [ ] 3-5문장 응답
- [ ] 질문 1개 이하
- [ ] 공감적 톤 유지
- [ ] 금지 표현 없음 (입양 권유, 망각 권유 등)

**장애 시 대처:**
- 응답 지연: "AI가 생각 중입니다" 멘트 후 대기
- 응답 오류: 다른 메시지로 재시도

---

### 시나리오 3: 위기 감지

**시연 단계:**
1. 위기 메시지 입력
2. 위기 모달 표시 확인
3. 전화 연결 버튼 확인

**시연 문장 (주의: 실제로는 입력하지 않고 설명만):**
- "이제 더 이상 살고 싶지 않아요."

**대안 (실제 시연):**
- 슬라이드/스크린샷으로 위기 모달 화면 보여주기
- 백업 시연 영상 활용

**확인 항목:**
- [ ] 위기 모달 즉시 표시
- [ ] 고정 안전 문구 표시
- [ ] 위기 전화 3개 링크 표시 (109, 1577-0199, 1566-2525)
- [ ] AI 생성 응답 없음

---

### 시나리오 4: 감정 기록 (5초 이내 저널 생성)

**시연 단계:**
1. "기록" 탭 선택
2. 저널 목록 확인
3. 저널 상세 선택

**확인 항목:**
- [ ] 저널 목록 날짜 역순 표시
- [ ] 저널 제목 30자 이내
- [ ] 감정 점수 4개 표시 (그리움, 죄책감, 무기력, 따뜻함)
- [ ] 의미 있는 순간 최대 3개
- [ ] 서사 표시

**장애 시 대처:**
- 저널 없음: 백업 시드 데이터 확인
- 로딩 오류: 새로고침 후 재시도

---

### 시나리오 5: 회복 흐름 시각화

**시연 단계:**
1. "마음 흐름" 탭 선택
2. 7일 그래프 확인
3. 14일 토글 후 확인

**확인 항목:**
- [ ] 4개 감정 선 그래프 표시
- [ ] 범례 표시 (그리움, 죄책감, 무기력, 따뜻함)
- [ ] 7일/14일 기간 토글 작동
- [ ] 날짜 레이블 표시

**장애 시 대처:**
- 그래프 미표시: 데이터 확인 (최소 2일치 필요)
- 렌더링 오류: 새로고침

---

### 시나리오 6: 데이터 격리 확인

**시연 단계:**
1. 휴대폰 A: `?start=demo` 진입 → 대화 전송
2. 휴대폰 B: `?start=demo` 진입 → 대화 조회
3. 서로의 데이터 미표시 확인

**확인 항목:**
- [ ] 각 세션마다 별도 익명 계정 생성
- [ ] 대화 내역 분리
- [ ] 저널 데이터 분리

**장애 시 대처:**
- RLS 오류 발생 시: Supabase 대시보드에서 RLS 정책 확인

---

## 리허설 진행 방법

### 준비물
1. 노트북 (시연용)
2. 휴대폰 2대 (데이터 격리 확인용)
3. 프로젝터/모니터 연결 케이블
4. 백업 시연 영상 (USB 또는 로컬 파일)
5. QR 코드 이미지 (인쇄물)

### 리허설 절차

**사전 점검 (시연 1시간 전):**
- [ ] 인터넷 연결 확인
- [ ] 배포 URL 접속 확인
- [ ] Edge Functions 정상 작동 확인
- [ ] 시드 데이터 확인
- [ ] 배터리 충전 (노트북, 휴대폰)

**리허설 1회차:**
1. 시나리오 1~6을 순서대로 실행
2. 각 단계별 소요 시간 측정
3. 실패 지점 기록

**리허설 2회차:**
1. 실패 지점 개선 후 재실행
2. 멘트 및 전환 타이밍 조정
3. 장애 대처 연습

**리허설 3회차:**
1. 실전처럼 처음부터 끝까지 연속 실행
2. 총 시연 시간 확인 (목표: 5~7분)
3. 최종 체크리스트 확인

### 시연 멘트 예시

**도입:**
"온곁 리멤버는 반려동물을 떠나보낸 보호자의 마음 회복을 돕는 AI 기반 정서 지원 서비스입니다. 지금부터 실제 작동하는 프로토타입으로 6가지 핵심 기능을 시연하겠습니다."

**시나리오 1 (체험 진입):**
"먼저, 누구나 3초 이내에 체험을 시작할 수 있습니다. QR 코드를 스캔하거나 링크를 클릭하면 별도 회원가입 없이 바로 홈 화면으로 진입합니다."

**시나리오 2 (공감 대화):**
"AI 동반자는 보호자의 이야기를 경청하고 공감합니다. 2초 이내에 응답이 시작되며, 자연스러운 대화 흐름을 유지합니다."

**시나리오 3 (위기 감지):**
"만약 보호자가 자해나 자살과 같은 위기 표현을 사용하면, AI는 즉시 이를 감지하고 전문 상담 기관으로 연결합니다. 이는 AI 안전성의 핵심 기능입니다."

**시나리오 4 (감정 기록):**
"매일의 대화를 바탕으로 AI가 자동으로 감정 저널을 생성합니다. 보호자의 감정 상태를 4가지 지표로 분석하고, 의미 있는 순간을 기록합니다."

**시나리오 5 (회복 흐름):**
"시간에 따른 감정 변화를 그래프로 시각화하여, 보호자가 자신의 회복 과정을 객관적으로 확인할 수 있습니다."

**시나리오 6 (데이터 격리):**
"각 사용자의 데이터는 철저히 격리되어, 다른 사용자의 정보는 절대 보이지 않습니다."

**마무리:**
"온곁 리멤버는 AI 기술로 펫로스 보호자의 마음 회복을 돕는 혁신적인 서비스입니다. 감사합니다."

## 백업 시연 영상

**촬영 내용:**
1. 시나리오 1~6 전체 과정
2. 각 화면 전환 및 기능 작동
3. 총 길이: 5분 이내

**촬영 도구:**
- 화면 녹화: OBS Studio 또는 QuickTime
- 해상도: 1920x1080
- 포맷: MP4

**저장 위치:**
- `docs/demo-backup-video.mp4`
- USB 백업
- 클라우드 백업 (Google Drive 등)

## 위기 장면 시연 문장

위기 감지 데모용 안전한 문장 (실제 위기가 아님을 명시):

**시연용 (모달 표시):**
- "이제 더 이상 살고 싶지 않아요." ← 실제 입력
- "자살하면 그 아이를 다시 만날 수 있을까요?" ← 실제 입력

**대안 (스크린샷):**
- 미리 촬영한 위기 모달 화면 이미지 표시
- 슬라이드에 캡처 이미지 삽입

## 장애 시 대처 매뉴얼

### 1. 인터넷 연결 끊김
- **대처:** 백업 시연 영상 재생
- **멘트:** "시연 환경의 일시적 문제로 미리 녹화한 영상을 보여드리겠습니다."

### 2. API 응답 지연
- **대처:** "AI가 생각 중입니다" 멘트 후 10초 대기
- **10초 초과:** 새로고침 또는 다른 메시지로 재시도
- **지속 실패:** 백업 영상 전환

### 3. Edge Function 오류
- **대처:** Supabase Dashboard에서 Functions 로그 확인
- **긴급 수정 불가:** 백업 영상 사용

### 4. 시드 데이터 없음
- **대처:** `?start=demo` 재진입으로 시드 재생성
- **실패:** 백업 계정 사용 (미리 준비)

### 5. PWA 설치 실패
- **대처:** 브라우저 새로고침 후 재시도
- **지속 실패:** 웹 버전으로 계속 진행

## 성공 기준

**3회 연속 성공:** 시나리오 1~6을 실패 없이 연속으로 완료

**각 시나리오 성공 조건:**
1. 체험 진입: ≤3초
2. 대화 응답: ≤2초 첫 글자
3. 위기 감지: 모달 표시
4. 저널 생성: 유효한 JSON
5. 대시보드: 그래프 표시
6. 데이터 격리: 분리 확인
